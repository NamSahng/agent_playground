# 메모에서 할 일 추출하기

사용자가 지정한 메모에서 확정된 할 일만 추출한다.
논의 예정인 주제를 확정된 작업으로 바꾸지 않는다.

출력은 객체 배열이며, 각 객체는 다음 필드를 갖는다.

- `task`: 할 일
- `owner`: 메모에 명시된 담당자. 없으면 `null`
- `due`: 메모에 명시된 기한. 없으면 `null`. 상대 날짜는 원문 그대로 유지한다.

담당자나 기한을 추측하지 않는다. 확정된 할 일이 없으면 `[]`를 출력한다.
파일 저장을 요청받으면 지정된 위치에 JSON을 저장하고, 그렇지 않으면 JSON을 답변한다.
