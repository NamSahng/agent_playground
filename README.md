# agent_playground

AI 개발 기술과 도구를 아주 작은 예제로 하나씩 직접 사용해 보는 실습 저장소입니다.
각 예제는 한 가지 기능이나 작업 흐름을 경험하고 결과를 확인할 수 있는 크기로 만듭니다.

개념 설명은 각 예제의 README에 몇 문장으로 작성하고, 자세한 내용은 원문 링크로 연결합니다.

각 예제의 README에는 다음을 간략히 기록합니다.

- 어떤 기술이며, 이 예제에서 무엇을 해보는지
- 필요한 준비와 실행 명령 또는 따라 할 절차
- 실행 후 확인할 결과
- 실제로 사용해 본 결과와 참고 링크

## 예제

문서 하나당 작은 실습 하나를 따라 해봅니다.
